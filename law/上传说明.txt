上传到 GitHub Pages 的步骤（网页点点点，不用装 git）
================================================================

1. github.com 右上角 + → New repository → 名字随便，比如 law-quiz
   → 可见性必须选 Public（免费账号的 Pages 只支持公开仓库）→ Create

2. 进仓库 → Add file → Upload files → 把本文件夹里的**所有文件**
   （index.html、sw.js、manifest.json、icon-180/192/512.png）一起拖进去
   → 底部 Commit changes

3. Settings → 左侧 Pages → Source 选 "Deploy from a branch"
   → Branch 选 main，目录选 / (root) → Save

4. 等 1~2 分钟，回到 Settings → Pages 页面顶部会显示网址：
   https://你的用户名.github.io/law-quiz/

5. iPhone 用 **Safari** 打开这个网址（微信/Chrome 点开不算）
   → 底部 分享按钮 → 添加到主屏幕 → 起个名字 → 添加

说明
----
* start_url 是 index.html，所以网址不带文件名，点主屏幕图标直接进。
* 全屏模式：加了 apple-mobile-web-app-capable，打开后没有 Safari 地址栏。
  不想要这个效果，就把 index.html 里那两行 web-app-capable 删掉重新上传。
* 离线：首次联网打开后会被 service worker 缓存，之后断网也能用。
  更新题库后必须把 sw.js 第一行的 CACHE 版本号改掉（lawquiz-v1 → v2），
  否则旧缓存不会刷新。重新生成这个文件夹跑：python scripts/make_pages.py
* 公开仓库任何人有链接都能访问。这是内部资料就别传公开仓库。
